# WORDLE | LAB
A minimalist, endless Wordle-inspired word game built as a frontend development project. Instead of limiting the experience to a daily puzzle, Wordle / Lab lets players keep playing through fresh rounds while tracking their progress, streaks, and best performance.

## Features
- Endless word-guessing rounds
- Six attempts per word
- Five-letter word puzzles
- Visual feedback for correct, misplaced, and incorrect letters
- Streak tracking
- Games played and solved statistics
- Best streak tracking
- New round system
- Dark mode
- Sound effects with adjustable volume
- Toggleable animations
- How-to-play guide
- Stats and settings panels
- Streak milestone notifications
- Responsive game interface

## How to Play
Guess the five-letter word within six tries. After submitting a guess:
- **Green** means the letter is in the correct position.
- **Yellow** means the letter is in the word but in the wrong position.
- **Gray** means the letter is not in the word.
Use your keyboard to enter letters, press **Enter** to submit a guess, and use **Backspace** to delete.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript
No frontend framework is required for the core game.

## Design
Wordle | Lab uses a clean, minimal interface with an editorial-inspired visual style. The interface focuses on typography, spacing, subtle motion, and a simple game surface rather than heavy visual effects.

The project also includes optional atmosphere controls such as dark mode, sound effects, and animations.
